# Token Atlas v0.3.0

这次更新重构了整个用量工作台，保留黑白主题、彩色 KPI 卡片和面积图风格，并加入真正的「全部日期」。

## 更新内容

- **四个清晰入口**：概览、用量分析、会话、数据源。
- **全部日期**：替换 90 天快捷选项，读取本机及所选设备的完整可用历史；日期范围显示实际首末记录。
- **一致的统计口径**：日、周、月、模型与导出共用同一范围；切换失败不会混用旧范围结果。
- **完整模型分布**：前五模型加其他 / 未归类用量，按少到多堆叠，深浅主题独立配色。
- **更直接的操作**：网页粘贴 / 文件导入、设备更新备份、会话搜索 / 分页 / 详情 / 导出。
- **Sonner 反馈**：刷新、导入、导出和复制有清晰的进行中、成功或失败提示。

## 复查修正

- Jetson 导出脚本默认导出全部历史，并兼容 ccusage、pnpm、npx。
- 命令行导入保留报告中的 Agent 来源，不再把导入时间假称为导出时间；更新保存上一份备份。
- 导入统一校验日期与模型数值，拒绝模型用量超过当日总量的报告。
- 一键启动不再依赖调用者的工作目录。
- 部署追踪排除私人设备报告；CI 扩展到 Windows 和 Ubuntu。

## 运行与升级

需要 Node.js 20.9+ 与 pnpm 10+。在 `ccusage-dashboard` 目录执行：

```bash
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

Windows 也可运行 `scripts/open-dashboard.ps1`。详细导入和部署说明见仓库 README。

已有 `data/devices/*.json` 可以继续使用。「全部日期」只覆盖当前机器实际保留、或外部设备已经导入的记录；若 Jetson 之前只导出了 90 天，请重新运行新的导出脚本并更新该设备。

API 参考价为 ccusage 离线估算，不是官方账单；外部每日汇总无法还原会话明细。
