## 价格口径

PowerShell 导入现在复用网页的校验器再写入，剔除正文与无关字段，无需启动网页服务；现有设备锁、备份和原子替换保持不变。编译临时目录只保存校验器代码，不保存报告；中文设备名在 Windows PowerShell 中按 UTF-8 传递。Shell 脚本明确保持 LF 换行，便于从 Windows 复制到 Ubuntu。

完整价格显示参考金额；全缺价显示“待定价”；部分缺价显示 `≥` 已定价小计。真正没有用量的自然日仍为零。未确认价格不能解释为免费，参考价不能解释为账单。外部汇总需要在原设备重新导出，本机升级不能从旧聚合中恢复缺失价格。

上游字段与配置依据：[ccusage JSON 输出](https://ccusage.com/guide/json-output)、[定价覆盖配置](https://ccusage.com/guide/config-files)、[v20.0.30](https://github.com/ccusage/ccusage/releases/tag/v20.0.30)。
